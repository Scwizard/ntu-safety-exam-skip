# ”南京工业大学安全知识考试“一键完成脚本

ntu-safety-exam-skip

**🤔 食用指导**

如果您是普通用户，您可以下载右边的Release版本，右键，选择以管理员身份运行。

如果您是专业用户或者希望研究本脚本的源代码，以下提供以源代码的方式运行此脚本：

1.安装Python3，确保环境变量配置正确。

2.克隆此仓库，并确保文件被完全解压。

3.切换到程序目录，安装 requests 库

```bash
pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple
```

4.运行主程序 main.py ，按照程序提示输入即可。
